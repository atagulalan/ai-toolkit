# Shared Cursor rule bundles

Optional `.mdc` / `.cursorrules` bundles for common stacks (Next.js, React Native, Redux, Styled Components, etc.).

These are **not** installed by the CLI. Canonical toolkit prompts live in `lib/prompts/`.

## Usage

Copy the bundle folder (or individual `.mdc` files) into your project’s `.cursor/rules/` when you need that stack.

## Contents

Bundles are curated for TypeScript / React / Next.js / React Native workflows used by the web team. Off-topic third-party dumps (Web3/Solidity, Memory Bank, Python services) are intentionally excluded.
